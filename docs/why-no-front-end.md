# Why there is no front end

A licensing accountant needs to explain a statement, find a missing approval and trace a number to a sales line. Those jobs work from records and repeatable commands. The database is the product. Claude Code, Codex, OpenCode or Cursor is the door.

`npm run view` produces private read-only HTML for the week, contract exposure and evidence review. `npm run docs` writes working licence briefs, royalty statements and evidence checklists. Set the business name, logo and colours in brand.json. Reports do not send, approve, pay or publish anything.

A screen provides mobile navigation, shared forms, artwork review, portals and side-by-side editing. This base has none of those, and it has no mobile sync, offline multi-user workflow or drag-and-drop approval. PGlite is a single-process local store. A shared installation uses PostgreSQL with an access and backup design.
