# /add-product

Register a product under one agreement.

Read CLAUDE.md first. Run npm run licensing -- add-product --json with the required flags from help: --agreement, --code, --name, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Present the observed result, amounts with currency and any unresolved exceptions. Actor names are labels, not authentication.
