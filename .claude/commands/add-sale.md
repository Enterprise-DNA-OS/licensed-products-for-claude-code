# /add-sale

Record an evidenced sales line.

Read CLAUDE.md first. Run npm run licensing -- add-sale --json with the required flags from help: --period, --product, --reference, --date, --territory, --currency, --gross-cents, --deductions-cents, --evidence, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Present the observed result, amounts with currency and any unresolved exceptions. Actor names are labels, not authentication.
