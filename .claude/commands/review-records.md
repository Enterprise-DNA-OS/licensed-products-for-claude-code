# /review-records

Record tax retention dates and the next purpose review.

Read CLAUDE.md first. Run npm run licensing -- review-records --json with the required flags from help: --agreement, --tax-year-end, --retain-until, --review, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Present the observed result, amounts with currency and any unresolved exceptions. Actor names are labels, not authentication.
