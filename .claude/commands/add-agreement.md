# /add-agreement

Enter signed licence terms from evidence.

Read CLAUDE.md first. Run npm run licensing -- add-agreement --json with the required flags from help: --code, --name, --licensor, --property, --territory, --category, --currency, --start, --end, --rate-bps, --minimum-cents, --advance-cents, --owner, --evidence, --review, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Present the observed result, amounts with currency and any unresolved exceptions. Actor names are labels, not authentication.
