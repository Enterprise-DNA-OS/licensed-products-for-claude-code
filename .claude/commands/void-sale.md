# /void-sale

Void an incorrect open-period sale while preserving its history.

Read CLAUDE.md first. Run npm run licensing -- void-sale --json with the required flags from help: --period, --sale, --reason, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Present the observed result, amounts with currency and any unresolved exceptions. Actor names are labels, not authentication.
