# /close-period

Freeze a reconciled period under a different reviewer.

Read CLAUDE.md first. Run npm run licensing -- close-period --json with the required flags from help: --period, --reconciliation, --actor. Read the relevant agreement or period before changing it. Resolve ambiguous names to an exact code or id.

Require the operator to name the reviewer and supply the reconciliation evidence. The reviewer must differ from the preparer. Never invent sign-off.
